# kggplot: Concise, Composable 'ggplot2' Plots from a Single Call

Draw a complete 'ggplot2' graphic (data reshaping, mappings, geometry,
labels, theme, palette, legend, facets) with a single short call, and
compose plots with the '+' operator through the 'kggplot' S3 class. Plot
types, themes and palettes live in extensible registries.
